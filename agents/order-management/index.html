Process

Contact. Classify. Sync.

The full order cycle runs autonomously. Your team sees a clean dashboard — not a phone queue.

01 — Contact
Agent reaches every customer
Before each delivery day, the agent sends a personalized message to every customer in the cycle — pre-filled with their standing order — and waits for a reply.
02 — Classify
AI reads every reply
Each inbound message is processed by Claude, which returns a structured intent: confirm, decline, modify, or question. The order state updates instantly. No manual triage.
03 — Sync
Confirmed orders enter ERP
Confirmed orders are pushed to Priority ERP via OData API the moment they're classified. No copy-paste, no manual entry. Overdue accounts are flagged automatically.
Capabilities

Built to run a full order
cycle without supervision.

Every feature came from watching a real coordinator spend their day on the phone.

Multi-channel Outreach
WhatsApp → SMS → Voice, with automatic escalation after each timeout. Each message is personalized with the customer's standing order, in Hebrew or English.
AI Reply Classification
Claude reads every inbound message and returns structured intent: confirm, decline, modify, or question. The order state updates instantly. Ambiguous replies go to a human, clear ones don't.
ERP Sync
Confirmed orders land in Priority ERP via OData API in real time. The local database is a coordination cache — Priority is the source of truth.
Immutable Audit Trail
Every agent action, customer reply, and state transition is appended to a log — nothing is ever updated or deleted. Full compliance history available on demand.
